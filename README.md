# Fur-riends — Backend Data Organization System

## Overview

Backend system designed to collect, structure and expose data from public sources through a REST API.

## Key Features

- Data collection and processing using Python (web scraping)
- Data normalization and conversion to structured JSON
- REST API built with Node.js (Express)
- Data validation and clean endpoint design
- Clear separation between business logic and routes

## Tech Stack

- Python (data collection & processing)
- Node.js + Express (API)
- JSON (data storage)
- Linux environment

## Purpose

This project demonstrates how to build a backend system that transforms unstructured data into structured, accessible information through APIs.
